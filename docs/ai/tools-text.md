# AI tools for text, styles and layout

The tools that read and find text, edit and format it, set styles, themes and page layout, and change tables. Part of the [AI pages](index.md); the other tools are in [headers, notes and fields](tools-parts.md), [equations, citations and charts](tools-content.md) and [raw ops](tools-raw-ops.md).

## Tools

| Tool | Purpose |
|---|---|

| `read_document` | DocScript, windowed for long documents (`start`, `limit`). |
| `get_outline` | Headings with ids. A document with tabs also lists them: `[tab t2] Name (paragraphs, words)`, nested by depth, each before the headings it holds. |
| `set_heading_level` | Promote or demote headings, or make paragraphs headings or body text. `ids`, then `level` (1 to 9, 0 for body text) or `delta` (-1 promotes, 1 demotes; body text promotes to a heading one level below the heading above it, a level 9 demotes to body text). With `with_subsections` the headings in the sections under each given heading change by the same amount. The raw op is `{"op":"set_outline_level","ids":[...],"level":2}` or `"delta":-1`. |
| `move_section` | Move a heading with everything under it (down to the next heading of its level or higher) to just after the block `after` or just before the block `before`. The raw op is `{"op":"move_blocks","ids":[...],"after":id}`: it moves top-level blocks in their own order, so list a heading and everything under it to move a section. |
| `search` | Paragraphs containing text, in the text, headers, footers, notes and text boxes. The query is plain text with Word's `^` codes (`^p`, `^t`, `^l`, `^m`, `^?`, `^#`, `^$`, `^^`), or with `wildcards` Word's wildcards, or with `regex` a JavaScript regular expression. Options: `ignore_case`, `whole_word`, `prefix`, `suffix`, `ignore_punct`, `ignore_space`, `ignore_marks`, `sounds_like`, `main_only`, and `find_format` (bold, italic, underline, strike, caps, smallCaps, font, size, color, highlight, vertAlign, style, lang, paraStyle, align). |
| `replace_text` | Find and replace (like `str_replace`), keeping the replaced text's formatting. It takes the options of `search`, and also `keep_case` (the replacement takes the capitals of the text it replaces), `\1` or `$1` for a group, `^&` for the found text, `^p` in `replace` to split a paragraph and in `find` to join paragraphs. Without `ids` it also replaces in headers, footers, notes and text boxes (`main_only` stops that). `format`, `para_format` and `language` put formatting on the replacement; with an empty `replace` they change the found text and leave its words alone. |
| `rewrite_paragraph` | Replace one paragraph's content with inline Markdown, keeping its style. |
| `insert_content` | Insert Markdown (headings, lists, quotes, code, tables, page breaks) after/before a block. |
| `insert_html` | Insert HTML (fonts, colours, lists, tables, links, `data:` pictures) after/before a block; reads what Word, Google Docs and web pages copy. |
| `delete_blocks` | Delete paragraphs/tables. |
| `format_text` | Character formatting for specific text in a paragraph: bold, italic, colour (a hex, or a theme colour with `themeColor`, `themeTint` and `themeShade`), size, font, all sixteen highlight colours, underline in any of Word's styles with `underlineColor`, `dstrike`, `vanish` (hidden), `outline`, `shadow`, `emboss`, `imprint`, `spacing`, `position` (raised or lowered, half-points), `scale` (percent), `kern`, `em` (emphasis mark), `shading`, `ligatures`, `numForm`, `numSpacing`, and `style` (a character style by name or id: `Strong`, `Emphasis`, or a linked heading style, which applies as its character twin; empty clears it). |
| `change_case` | Change the case of text in a paragraph (`text`, or the whole paragraph) to `sentence`, `lower`, `upper`, `title` or `toggle`, keeping the formatting. Casing follows the paragraph's language (Turkish has a dotted and a dotless i). |
| `set_link` | Link or unlink text. |
| `set_paragraph_style` / `format_paragraphs` | Styles, alignment (also distribute), spacing, line spacing (a multiple, exactly or at least), indents (left, right, first line or hanging), mirror indents, tab stops (`tab_stops`: position, kind left, center, right, decimal or bar, and a leader; the list replaces the paragraph's own), text direction (`direction`: ltr or rtl), outline level, lists, pagination (keep with next, keep lines together, page break before, widow control, don't hyphenate), "don't add space between paragraphs of the same style", shading and borders. In a right-to-left paragraph `left` is the start side, as in Word's file. |
| `insert_break` | Page, column and section breaks (`next_page`, `continuous`, `even_page`, `odd_page`) after some text. Section breaks show in DocScript as `section_break=…` on the paragraph that ends a section. |
| `set_page_layout` | Orientation, margins, columns, line numbers, page colour, hyphenation and page numbering (restart, format), for the whole document or one section. |
| `apply_ops`, `expand_alt_chunk` | `id`: any block of an imported chunk (HTML, text, RTF, a web archive or a .docx a tool put in the file as `w:altChunk`). Makes it ordinary content; any edit inside a chunk does this by itself, in the same undo step. |
| `apply_ops`, table of authorities | `{op: "toa", action}`: `mark_citation` (`at`, `from?`, `long`, `short?`, `category` 1 to 16, `bold?`, `italic?`), `mark_all` (`long`, `short?`, `category`, `ignore_case?`), `insert` (`after?` or `before?`, `options?`: `{category?, passim?, keepFormatting?, headings?, rightAlign?, leader?, pageSep?, rangeSep?, look?}`, `pages?`), `set` (`at?`, `options`), `update` (`at?`, `pages?`; `update_fields` updates the tables too) and `set_category_names` (`names`: `[{category: 8 to 16, name}]`). |
| `apply_ops`, document tabs | `{op: "tab", action}`: `add` (`name?`, `icon?`, `parent?`, `after?`, `first_name?` for a document without tabs, `open?`), `rename` (`id`, `name`), `set_icon` (`id`, `icon?`), `delete` (`id`), `duplicate` (`id`, `name?`), `move` (`id`, `parent?`, `before?`); which tab is open is the person's view, not an op. `get_outline` lists the tabs (id, name, depth, paragraphs and words) with the headings under the tab they are in. Each tab after the first starts a new section, so Word shows the tabs one after another. |
| `apply_ops`, page layout ops | Everything past `set_page_layout`, as raw ops (twips; leave out `section` for every section, `from: true` for that section and the ones after it): `set_section` (`gutter`, `rtl_gutter`, `header` and `footer` distances, `v_align`: `top`, `center`, `both` or `bottom`, `text_direction`, `start`, `no_endnote`), `set_page_borders` (`borders`: `{offsetFrom, display, zOrder, top?, left?, bottom?, right?: {val, sz, space, color, shadow?}}` or `null`; art border names draw as plain lines on screen), `set_columns` with `widths` and `spaces` for unequal columns, `set_page_numbering` with `chap_style` (1 to 9, or 0 to remove) and `chap_sep` for chapter page numbers (2-1), `insert_page_number` (`place`: `top`, `bottom`, `margin_left` or `margin_right`, `align?`, `style?`: `plain` or `x_of_y`, `page_word?`, `of_word?`, `variant?`; it replaces the page number already there) and `remove_page_numbers`, `insert_cover_page` (`design`: one of `Engine.pageGallery("cover")`, or `fragment`; `labels?`) and `remove_cover_page`, `insert_page_part` (`kind`: `header` or `footer`, `design`, `section?`, `labels?`), `set_layout_settings` (`mirror_margins`, `gutter_at_top`, `even_and_odd_headers`, `book_fold`, `book_fold_sheets`, `print_two_on_one`, `hyphenation_zone`, `consecutive_hyphen_limit`, `do_not_hyphenate_caps`; 0 removes a number), `set_page_background` (`fill`: `{kind: solid|gradient|radial|pattern|texture|picture, color?, color2?, angle?, from?, media?, title?}` or `null`; the image kinds name a part added through the engine first), `set_note_props` (`kind`, `section?`, `from?`, `format?`, `start?`, `restart?`: `continuous`, `eachSect` or `eachPage`, `pos?`: `pageBottom`, `beneathText`, `sectEnd` or `docEnd`) and `insert_custom_note` (`at`, `kind`, `mark`, `text?`: a note whose mark is text you give), `set_frame` (`ids`, `frame`: `{w?, h?, hRule?, wrap?, hAnchor?, vAnchor?, x?, y?, xAlign?, yAlign?, hSpace?, vSpace?}` or `null`) and `set_drop_cap` (`id`, `kind`: `none`, `drop` or `margin`, `lines?`, `distance?`, `font?`; the first letter moves into a frame of its own, as Word does it). |
| `edit_table` | Add/delete rows and columns. |
| `define_style` | Change what a style looks like for every paragraph or run that uses it, or make a new style. `style` is a name or id (Word's built-in styles can always be used); only the settings given change: `font`, `size_pt`, `bold`, `italic`, `underline`, `color`, `align`, `space_before_pt`, `space_after_pt`, `line_spacing`, `indent_left_pt`, `indent_right_pt`, `first_line_indent_pt`, `keep_with_next`, `page_break_before`, `based_on`, `next`, `in_gallery`, `auto_update`, `hidden`, and `name` and `kind` (`paragraph`, `character`, `linked`) for styles you make. The raw op is `{"op":"set_style_definition","style":"Heading 1","def":{"rpr":{"size":22,"bold":true},"ppr":{"spaceAfter":240}}}`. |
| `create_style_from_selection` | Make a style from how a range of text is formatted now (`name`, `id`, `from`, `to`, `kind`); the text takes the style. |
| `delete_style` | Delete a style you or the document made; paragraphs that used it fall back to the style it was based on. Word's built-in styles stay. |
| `list_design` | The document's theme (colours and fonts) and what can be chosen: themes, colour schemes, font schemes, style sets and paragraph spacing presets. |
| `set_theme` | Change the theme: a whole one (`theme`: Office, Facet, Integral, Ion, Wisp, Wood Type...), only its colours (`colors_scheme`, or `colors` for single slots such as `accent1`) or only its fonts (`fonts_scheme`, or `heading_font` and `body_font`). Text, headings, tables, shapes and charts that use theme colours or fonts follow. The raw op is `{"op":"set_theme","theme":"facet"}`. |
| `set_style_set` | Apply a style set (Word 2013+, Word 2010, Word 2003, Basic (Elegant), Lines (Simple), Minimalist, Shaded...): Normal, Title, Subtitle, Heading 1 to 9 and Quote and the default paragraph spacing are written again. |
| `set_paragraph_spacing` | `preset`: `default`, `none`, `compact`, `tight`, `open`, `relaxed` or `double`. |
