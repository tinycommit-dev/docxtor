# AI tools for headers, notes, objects and fields

The tools for headers and footers, notes, drawing objects, captions, cross-references, tables of contents, the index, fields, mail merge and bookmarks. Part of the [AI pages](index.md), after [text, styles and layout](tools-text.md).

## Tools

| Tool | Purpose |
|---|---|

| `set_table_design` | Give a table one of Word's built-in designs (`design`: `Table Grid`, `Plain Table 1` to `5`, `Grid Table 1 Light` to `7 Colorful`, `List Table 1 Light` to `7 Colorful`, the last two also with ` Accent 1` to `6`, or a table style the document already has) and set the style options `header_row`, `total_row`, `first_column`, `last_column`, `banded_rows`, `banded_columns`. `cell` is any paragraph in the table. The raw op is `{"op":"table_design","at":<paragraph in the table>,"style":"Grid Table 4 Accent 1","look":{"firstRow":true,"bandedRows":false}}`. |
| `set_header_footer` | Set the page header/footer text (inline Markdown); `{PAGE}` and `{NUMPAGES}` become live fields. Takes a `section` to change one section's, and `link_to_previous` (Word's Link to previous: `true` shows the previous section's again, `false` gives the section its own copy; `text` is then optional). |
| `insert_footnote` | Add a numbered footnote after some text. |
| `insert_endnote` | Add an endnote (listed at the end of the document, numbered i, ii, iii by default) after some text. |
| `list_objects` | Every drawing object of the document (shapes, text boxes, pictures, charts, groups): its position `{p, o}`, kind, name, wrapping, stacking value, whether it is hidden and where a floating one is placed. The positions are what `set_object_props`, `set_object_position` and `move_object` (in `apply_ops`) take. |
| `insert_text_box` | A text box (a white rectangle with a thin black outline, floating beside the paragraph with square wrapping) anchored after `after_text` in a paragraph. `text` is its content, one paragraph per line; the result lists the paragraph ids inside the box, and the ordinary text tools (`replace_text`, `rewrite_paragraph`, `format_text`, ...) edit them. Optional `width`, `height`, `floating`, `x`, `y` (points). |
| `insert_shape` | A drawing shape (`shape`: a Word preset such as `rect`, `roundRect`, `ellipse`, `triangle`, `rightArrow`, `star5`, `line`, or a plain name like `rectangle`, `oval`, `arrow`) anchored after `after_text`, with optional `text`, `fill` (hex or `none`), `line` (hex or `none`), `line_width`, `width`, `height`, `floating`. |
| `insert_caption` | A numbered caption paragraph (style `Caption`) next to a block: `after` puts it below, `before` above. `label` is `Figure`, `Table`, `Equation` or your own; numbers are per label, in document order, and later captions renumber. `chapter_level` (with `chapter_separator`) numbers it by chapter, "Figure 2-1". |
| `list_cross_reference_targets` | What a cross-reference can point at: headings (with their numbers), captions, bookmarks, footnotes and endnotes, with the ids to use below. |
| `insert_freeform` | A curve or freeform (a shape with its own outline, as Word's Curve, Freeform and Scribble tools make) anchored after `after_text`: `points` (`[x, y]` pairs in points, at least two), `smooth` (a curve through them rather than straight segments), `closed` (join the last point to the first; a closed shape gets a fill, an open one none), optional `fill`, `line`, `line_width`, `floating`, and `x`, `y` for where the first point sits. |
| `insert_cross_reference` | A live cross-reference field in a paragraph after some text. `target` is `{"type":"heading","p":"p12"}`, `{"type":"caption","p":"p30"}`, `{"type":"bookmark","name":"Intro"}`, `{"type":"footnote","id":"2"}` or `{"type":"endnote","id":"1"}`; `show` is `text`, `number`, `page`, `label_number` (a caption's "Figure 1"), `caption_text`, `number_no_context`, `number_full_context` or `number_formatted` (a note's mark); `link` (default true) makes it a link, `above_below` adds "above" or "below". |
| `mark_index_entry` | Mark text for the index with a hidden `XE` field: after the first occurrence of `text` in a paragraph, or with `all` the first occurrence in every paragraph. `entry`, `sub` (a sub-entry) and `see` (text such as "See Fruit" shown instead of page numbers) are optional. |
| `insert_table_of_contents`, `change_table_of_contents`, `remove_table_of_contents`, `add_table_of_contents_entry` | The table of contents with its options (levels, other styles with a level each, outline levels, table entry fields, links, page numbers, right alignment, leader, look); changing the one that is there; removing it; and a hidden `TC` line for text that isn't a heading. |
| `change_index`, `auto_mark_index` | Change the index's options (columns, run-in, right-aligned numbers, leader, separators, language, look) and rebuild it; mark every listed text like an AutoMark file. `insert_index` takes the same options. |
| `insert_citation_placeholder`, `list_building_blocks`, `insert_building_block` | Cite a source that has only a tag so far; list and insert the quick parts a document's glossary holds. |
| `insert_index` | Insert the index built from the marked entries after (or before) a block, in a continuous section of its own with `columns` (default 2): sorted without regard to case or accents, sub-entries indented, page numbers merged (`4–6`). |
| `insert_table_of_figures` | A table of figures listing the captions with a `label`, with page numbers. |
| `update_fields` | Update caption numbers, cross-references, the table of contents, tables of figures, the index and the fields that show a value (like F9 in Word): dates and times, document properties, file name, word count, `IF`, `SET`, `QUOTE`, formulas, with their `\#`, `\@` and `\*` switches. Locked fields stay. Page numbers outside the editor are estimated, `NUMPAGES` is left alone, and unknown fields are left as they are. |
| `insert_field` | Insert a field in a paragraph, after some text: `field` is the instruction, such as `DATE \@ "MMMM d, yyyy"`, `DOCPROPERTY Company`, `= SUM(ABOVE)` or `STYLEREF "Heading 1"`. Its result is worked out when it goes in. |
| `list_fields` | Every field with its paragraph, instruction and result. |
| `set_field_code` | Change a paragraph's field (`index`, default the first) to a new instruction and work out the result again. The ops behind them are `insert_field`, `set_field_code` and `set_field_result` (`apply_ops`), and `update_fields` takes `open`, `quiet`, `only` and an `input` with the time, user, file and page count. |
| `mail_merge_info` | The document's mail merge: the kind of document (letters, labels, envelopes, directory), where the recipients came from, their columns and the first few records, how many are in the merge, and the merge fields in the text. |
| `start_mail_merge` | Start a mail merge: `type` (`letters`, `labels`, `envelopes`, `directory`) and `csv`, the recipients as text with a header row (comma, semicolon or tab separated). Word's settings (`w:mailMerge`) are written and the recipients are kept in the file. |
| `insert_merge_field` | Insert a merge field or rule in a paragraph at an offset: `{kind: "field", name}` (with `before`, `after`, `case`, `picture`), `address_block`, `greeting_line`, `if`, `ask`, `fill_in`, `next`, `next_if`, `skip_if`, `merge_rec`, `merge_seq` or `set`. They are Word's complex fields. |
| `preview_merge_record` | The text a record gives when the document is merged with it (`record`, from 1). The document is not changed. The ops behind the merge are `set_mail_merge`, `set_merge_recipients`, `insert_merge_field`, `update_labels`, `make_labels` (a sheet of labels as a table, from a `spec` in twips) and `insert_envelope` (a new first section with the envelope's page size). |
| `add_bookmark` / `delete_bookmark` | Name a phrase (or a whole paragraph) so links can point at it, or remove a name. Names start with a letter and have only letters, digits and underscores (40 characters at most) and must be new. Link to one with `set_link` and a `#Name` url. |
