# Docxtor documentation

Docxtor is a free, open-source editor for Word (.docx) files that runs in the browser, with an engine written in Rust. It opens a real `.docx`, edits it on pages and saves it back intact, and any AI model can work on your documents through the same tools.

- [Use Docxtor](use/index.md): what it is and how to open the app.
- [Embed and extend](embedding.md): put the editor in your own page, add [extensions](extensions/index.md), and use the [AI tools](ai/index.md) from the app, the command line or an MCP server.
- [Self-host](deploy.md): run your own copy, with [the browsers it needs](browsers.md), [how closely it matches Word](fidelity.md), [what leaves your browser](../PRIVACY.md) and [how to report a problem](../SECURITY.md).
- [Contribute](../CONTRIBUTING.md): set up a checkout, see [how the pieces fit](architecture/index.md) and [how speed is measured](performance/index.md).

What is done, what is next and what comes later is on [the roadmap](roadmap.md).
