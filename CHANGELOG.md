# Changelog

All notable changes to Docxtor are written here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project aims to follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html) once it has a first release.

## [Unreleased]

Nothing has been released yet. What exists today:

- A Rust engine that opens, edits and saves `.docx` files without dropping what it doesn't model (untouched parts stay byte-identical), compiled to WebAssembly for the browser and to native code for a command-line program (`docxtor`) and an MCP server (`docxtor-mcp`).
- A web app with paged layout, tables, pictures, equations, headers and footers, footnotes, lists, styles, find and replace, spelling and grammar checks, citations, a document library with version history, and an AI assistant that edits through the same tools as the CLI and MCP server.
- Three npm packages (`@docxtor/core`, `@docxtor/extensions`, `@docxtor/editor`) and a `<docxtor-editor>` element for embedding the editor, with an extension API.
- Licence notices for everything that ships, generated by `npm run notices` and checked in CI.
- Ways to run your own copy: a self-hosting archive and a Docker image (`docxtor-web`, unprivileged nginx on port 8080) with the same security headers as the hosted app, and a plain notice when the app is served without HTTPS.

Not yet: comments and tracked changes, published packages, and a tagged release.
